### [데일리실습/과제 제출 가이드] SSAFY16기 광주3반 알고리즘 
 --------------------

1. 소스코드 파일명 규칙: Solution_문제번호_교육생이름.java 
    * 예시: Solution_1289_홍길동.java


2. 주석 작성 : 알고리즘 소스코드에 구현 로직에 도움이 될 수 있는 주석을 작성해주세요.

3. 해결한 알고리즘 문제들은 초대 받은 GITLAB 프로젝트에 업로드 제출


4. "문제사이트\문제번호_문제명폴더>" 에 알고리즘 소스코드 업로드 (반드시 java 소스 파일만!) 
- 예시: SWEA\1289_원재의 메모리 복구하기 > Solution_1289_홍길동.java

5. 실습/과제문제 제출시 수행결과 화면캡처 제출하지 않아도 됨!!

6. 주어진 실습을 모두 완료한 경우만 개인 문제 풀어도 됨

7. commit 메시지 작성 규칙은 지정하지 않겠습니다.
